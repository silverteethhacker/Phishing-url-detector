# Dataset

This directory is intended for the dataset used for training and evaluating the Phishing URL Detector.

## Purpose

The dataset contains URL samples used to train the Machine Learning model to distinguish between potentially phishing and legitimate URLs.

## Data Processing

Before training, the dataset is processed and relevant URL characteristics are converted into features suitable for Machine Learning.

## Privacy

Do not store personal information, credentials, private URLs, API keys, or other sensitive information in this directory.

## Note

Large datasets and sensitive data should not be uploaded to the public GitHub repository unless their redistribution is permitted.
